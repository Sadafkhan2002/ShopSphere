# ShopSphere

ShopSphere is a full-stack e-commerce portfolio project inspired by modern fashion and lifestyle online stores.

## Technology Stack

- Frontend: React, Vite, Tailwind CSS, Redux Toolkit
- Backend: Node.js, Express
- Database: MySQL
- ORM: Sequelize
- Authentication: JWT and Google OAuth
- Payments: Stripe test mode and Cash on Delivery

## Project Structure

- frontend/ — React application
- backend/ — Express API

## Status

Development in progress.
